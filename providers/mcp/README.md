# providers/mcp/

Documentation-only placeholder. MCP (Model Context Protocol) is an
**optional future integration layer**, not a hard dependency for the MVP —
see [`docs/architecture.md`](../../docs/architecture.md#agentic-orchestration).

The idea: expose Translation / TTS / Image Generation / Video Generation /
Rendering / Verification tools to agents via MCP once a provider is
selected, instead of (or in addition to) direct SDK calls in `providers/`.
No code here in Phase 0.
